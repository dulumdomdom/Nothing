**Синхронизация с внешней системой** (sequence_sync):
1. Пользователь редактирует запись в SPA → `PUT /api/items/:id`
2. Backend сохраняет и отвечает `200 OK`, пользователь видит подтверждение
3. **Асинхронно** Backend отправляет Webhook (JSON) внешней системе
4. Возможные исходы: `200 OK` (успех), `409 Conflict` (конфликт версий — фиксируется в ConflictLog, побеждает MDM), `5xx/Timeout` (статус failed)

**Декодирование шифра** (sequence_decode):
1. Пользователь вводит шифр (например, `321`) в панель декодирования
2. SPA → `POST /api/classifiers/:id/decode`
3. Backend загружает из PostgreSQL дерево узлов с фасетами
4. Разбор справа налево: каждый фасет вырезает фрагмент заданной длины из хвоста строки, сверяет с ValueMap
5. При успехе → возвращается расшифровка по сегментам (например, `3`→«Труба», `2`→«Ст45», `1`→«Калибр 20»)
6. Если шифр не найден — ошибка
